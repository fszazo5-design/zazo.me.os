# Zazo Brand

واجهة React/Vite لعرض المشاريع والفيديوهات، مع API serverless على Vercel وقاعدة بيانات Neon. الموقع يحفظ **الروابط فقط**: رابط الصورة ورابط العرض أو الفيديو، ولا يرفع ملفات ثنائية إلى الخادم.

## إعداد Neon وVercel

نفّذ الملف `neon/schema.sql` مرة واحدة داخل Neon SQL Editor. بعد ذلك أضف متغير البيئة التالي في إعدادات Vercel:

| المتغير | الاستخدام |
| --- | --- |
| `DATABASE_URL` | رابط اتصال Neon السري |
| 
## لوحة الإدارة

لوحة الإدارة منفصلة عن الواجهة العامة في المسار الواضح `/admin`، ولا تظهر في قائمة التنقل. المسار `/control-panel` متاح أيضًا للتوافق مع الروابط القديمة. أضف نوع المحتوى والتخصص والعنوان وروابط الصورة والمحتوى، وسيقوم API المباشر `https://zazo-me-os.vercel.app/api/content` بالحفظ في Neon، بينما تقرأ الصفحات العامة البيانات حسب التخصص عبر نفس API.

لا تضع `DATABASE_URL` داخل ملفات `VITE_*` أو داخل GitHub؛ يبقى داخل بيئة API في Vercel.
