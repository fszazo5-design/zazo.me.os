# مصدر محتوى الموقع

هذه الملفات هي مصدر البيانات الوحيد للموقع، ويتم تحميلها مباشرة من المستودع:

- `projects.json` — المشاريع والبرامج والتطبيقات
- `system-videos.json` — فيديوهات شرح الأنظمة
- `content-videos.json` — فيديوهات صناعة المحتوى
- `stats.json` — الإحصائيات الظاهرة في الصفحة الرئيسية
- `categories.json` — تصنيفات معرض المشاريع

يمكن استخدام المسار `/admin` لرفع مصفوفة JSON مباشرة إلى الملف المناسب عبر GitHub Contents API. يحتاج الرفع إلى Fine-grained GitHub Token بصلاحية `Contents: Read and write` على هذا المستودع فقط. الرمز لا يُحفظ في الموقع أو `localStorage`.

الصور المحلية توضع داخل `public/` ويُستخدم مسارها مثل `/zazo.jpg`. بعد دفع الملف إلى GitHub، يقرأ الموقع البيانات الجديدة في أول تحميل لاحق.
